# Interpretácia výsledkov

- Stĺpec s viac než 30 % prázdnych hodnôt spomeň ako problém kvality dát.
- Číselný stĺpec, kde max je mnohonásobne väčší než priemer, môže obsahovať extrém (preklep, zlá jednotka).
- Text s veľmi málo unikátnymi hodnotami je pravdepodobne kategória; s unikátnymi hodnotami v každom riadku je to identifikátor.
- Dátumy sa tu čítajú ako text – napíš, že formát treba skontrolovať.
