# README a dokumentácia

1. Zisti, čo projekt naozaj robí: list_files, code_map, prečítaj hlavný súbor a prípadné AGENTS.md. Nepíš nič, čo si v kóde nevidel.
2. Štruktúra README (vynechaj sekcie, ktoré nemajú obsah):
   - názov a jedna veta, čo projekt robí,
   - požiadavky (verzia Pythonu, knižnice z requirements.txt),
   - inštalácia a spustenie – presné príkazy, ktoré si overil (run_code, kde sa dá),
   - príklad použitia (vstup → výstup),
   - štruktúra súborov (1 riadok na súbor),
   - známe obmedzenia.
3. Existujúce README neprepisuj celé: edit_file len zastaraných častí.
4. Príkazy a názvy súborov kopíruj z projektu, nie z pamäte.
5. Jazyk README = jazyk používateľa (predvolene slovensky).
